# Mamayo Kitchen

MVP pemesanan makanan untuk warung Mamayo Kitchen. Aplikasi mencakup katalog, keranjang, checkout pembayaran manual, pelacakan pesanan, dan dashboard pemilik.

## Menjalankan

```bash
npm install
npm run dev
```

Data demo disimpan di `localStorage` browser. Dashboard pemilik menggunakan kata sandi demo `mamayo`; autentikasi ini hanya untuk prototipe frontend dan perlu diganti dengan autentikasi backend sebelum produksi.

## Pemeriksaan

```bash
npm run test
npm run build
```
